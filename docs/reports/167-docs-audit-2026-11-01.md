## 1. Why this exists

The operator noticed `OVERVIEW.md` is badly out of date ("quite outdated, not reflecting
the current state").  An audit of the canonical docs found that the real problem is
structural: **current status is restated in six places**, so when a session changes a
fact only the file it happened to touch gets updated, and the rest drift silently.

Example of the failure mode: `ARCHITECTURE.md:143` still says "**The bridge is never
programmed**" while `ROADMAP.md:24` says "The reference *does* program the bridge
(report 125)".  Both are canonical documents; a reader has no way to know which is
current.

## 3. Root cause

Current status is duplicated across `OVERVIEW`, `STATE`, `HANDOFF`, `ROADMAP`,
`ARCHITECTURE` and `README`.  A session updates the one it touched, and the others keep
the old sentence.  Nothing in the tree says which document owns which kind of fact.

## 4. Proposed ownership model (declare it once, in `docs/README.md`)

| doc | owns | must not contain |
|---|---|---|
| `OVERVIEW.md` | what/why, hardware, boot chain | status tables, unit state, "what works" |
| `STATE.md` | **the** current state, date-stamped | history (move below a divider) |
| `HANDOFF.md` | the next-session kickoff, copied at wrap-up | anything not needed to start |
| `ROADMAP.md` | what is next and what closes it | prose about the present |
| `ARCHITECTURE.md` | components and how they interact | status |
| `KNOWN-ISSUES.md` | traps, and corrections to older reports | current state |
| `README.md` | the index and this ownership table | session counts or ranges |
| `SAFETY.md` | what may be written, by whom | status |

Two conventions to add:

* **A freshness stamp as the second line of every canonical doc**:
  `Verified at session N (YYYY-MM-DD)`.  A doc stamped before the newest session note is
  suspect by definition; that alone would have caught findings #1-#13.
* **A mechanical guard, `tools/docs_audit.py`** (to be written): flag
  * session counts and ranges (`\b(twelve|N) sessions\b`, `session-01 … session-NN`,
    `absolute \d+…\d+`) whose N is older than the newest note;
  * a curated stale-phrase list — start it with the exact strings from §2:
    `never programmed`, `reboots unconditionally`, `180 s`, `no root filesystem`,
    `twelve sessions`, `two working 64 GB`, `never arm the reference`,
    `both live units`, `CFP.exe resetqnxosregion`, `half-armed`, `do not reboot`,
    `image-stock`;
  * removed tool names (`bbinfo`, `bbflash`, `pbreset`, `qcfm`);
  * missing or stale `Verified at session N` stamps;
  * report references (`report NNN`) that do not resolve to a file.
  Run it as the last step of the wrap-up checklist in `docs/sessions/README.md`.
